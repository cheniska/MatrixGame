# Редактор карт PB: прототип на Unity

Основной способ запуска — отдельный `PBMapEditor.exe`. Unity Hub нужен для
разработки и пересборки. Локальная проверенная сборка находится в
`E:/disasm2500_dev/MatrixGame_analysis/PBMapEditor_v13`; запускайте
`PBMapEditor.exe` из этой папки вместе с `PBMapEditor_Data`, `Models` и
`Catalog/data.txt`.
Рядом лежит тестовая карта `Maps/Training.map`, которая загружается при старте.
`Models` — локально извлечённые ресурсы игрового `DATA/robots.pkg`; они не
добавляются в Git и не изменяют установленную игру. `Catalog/data.txt` взят из
предоставленного архива старого MapEditor и связывает типы местности с PNG.
Если ресурсы находятся в
другом месте, укажите каталог с папкой `Matrix` в поле **Model root** и нажмите
**Reload**.

Поле **Source .map** принимает путь к другой карте редакторного формата;
нажмите **Load**. Поле **Save as** задаёт новый файл; **Save** сохраняет копию
карты. Существующий файл не перезаписывается. Колесо мыши меняет масштаб,
WASD или стрелки двигают камеру, щелчок по модели выбирает объект. Клавиши IJKL
двигают выбранный объект по клеткам, PgUp/PgDn меняют его высоту, `,` и `.`
поворачивают. Для выхода нажмите **Exit**, **Esc** или крестик окна.
Постройки, пушки и стартовые роботы показаны отдельно от обычных объектов.
Щелчок по их модели выбирает сущность; IJKL перемещают её по клеткам. Пушки
можно приподнимать PgUp/PgDn и поворачивать `,`/`.`; постройки поворачиваются
на 90°. Изменения положения и поворота сохраняются в соответствующих таблицах
`.map`. Комплектация робота пока не редактируется.
Кнопка **3D view** или клавиша **C** включает перспективу. В ней удерживайте
правую кнопку мыши и двигайте мышь для вращения камеры; WASD перемещают точку
обзора, Q/E меняют её высоту, колесо приближает и отдаляет. Shift ускоряет
перемещение. **Top view** или **C** возвращает вид сверху.
Справа находятся вкладки **Brushes**, **Entities** и **Players**. Размещённые
объекты и сущности выбираются щелчком по модели или строке списка. Все части
выбранной составной модели подсвечиваются. **Object types** открывает каталог
типов: выбор типа меняет выделенный объект и задаёт тип для **Add at center**.
**Delete selected** удаляет объект. **Height brush** редактирует высоты вершин:
щелчок повышает на единицу, Shift+щелчок понижает. В **Players** редактируются
ресурсы четырёх сторон, параметры ИИ и общий период подкреплений; **Save as**
записывает изменения в новый `.map`.

Проект рассчитан на Unity 6000.2.5f1. Для разработки откройте каталог
`Extras/MapEditorUnity` через Unity Hub. Созданные сцена и меш лежат в
`Assets/Generated` и не попадают в Git. Игровые файлы прототип не изменяет.

## Как попробовать

1. Выберите в меню Unity **PB Map → Import editor .map...** и укажите карту
   редакторного формата. Для проверки подходит `Training.map` из архива старого
   MapEditor.
2. В окне Scene появятся рельеф и кубы на местах объектов. Выберите куб и
   переместите его обычным инструментом Unity. Чтобы увидеть всю карту,
   выберите объект Terrain и нажмите **F**.
3. Выберите **PB Map → Save editor .map as...** и задайте **новый** путь.
   Существующий файл не перезаписывается. Экспорт также остановится, если
   исходная карта изменилась или какой-либо объект удалён из сцены.

Импорт читает исходные байты `CStorage`. Экспорт меняет в их копии только
координаты, высоту и угол поворота перемещённых объектов. Неизвестные таблицы
и поля остаются побайтно прежними.

## Пока не реализовано

Текстуры местности показывают по одному представителю каждого типа из палитры;
случайные варианты клеток, переходы и вода пока не воспроизводятся как в игре.
Верхние тайлы и поверхности показываются с приближённой укладкой по рельефу;
их точные игровые переходы и шейдеры ещё не перенесены. Отдельный `.exe`
показывает первый кадр доступных
`.vo`; неподдерживаемые или отсутствующие модели остаются кубами. DDS с
неизвестными кодеками пока не декодируются. `Training.map` ссылается на
`Head7.vo`, которого нет в доступном пакете моделей. В Unity Hub расширение
редактора всё ещё показывает кубы.
Нет инструментов для изменения типа/стороны построек и
пушек, комплектации роботов, эффектов, поверхностей, палитры текстур и свойств
карты. Нет отмены действий, системного выбора файла, импорта или экспорта
`.cmap`. Карты после
добавления/удаления объектов и изменения рельефа ещё не проверялись в старом
MapEditor и PBEngine.
