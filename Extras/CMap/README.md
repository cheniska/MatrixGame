# Формат карт `.cmap`

Карта планетарного боя — файл `CStorage` с заголовком `STRG`, версия 0.
В отличие от `robots.dat`, внешнего слоя `ZL03` у проверенных карт нет.
После заголовка идут именованные таблицы; каждая содержит колонки `CDataBuf`
с типом элемента и массивами. Загрузчик находится в
`MatrixGame/src/MatrixMapPrepare.cpp` (`CMatrixMap::PrepareMap`).

На 84 картах из штатного `DATA/robots.pkg` и одной карте PBNewMaps найдены
одни и те же 18 таблиц: `bitmaps`, `bottom`, `bridges`, `buildings`, `cannons`,
`effects`, `groups`, `inshores`, `move`, `objects`, `points`, `properties`,
`roads`, `robots`, `strings`, `surfaces`, `surfacesM`, `texunions`.

Для геометрии и маршрутов особенно важны:

- `properties/Name,Value`: параметры карты, включая `SizeInUnitsX/Y`.
- `points/Data`: `(X+1) × (Y+1)` структур `SCompilePoint` по 12 байт:
  индекс шаблона движения, высота `float`, цвет BGR, флаги клетки.
- `move/Data`: словарь `SCompileMoveCell` по 64 байта. Каждый шаблон хранит
  четыре подячейки; у каждой есть зона, маска запрета движения по типам шасси,
  `Sphere` и `Zubchik`. Загрузчик разворачивает их в сетку `2X × 2Y`.
- `roads/Data`: сериализованная `CMatrixRoadNetwork`. Первый DWORD — версия
  формата; все 85 проверенных карт используют версию 27. Затем идут зоны,
  узлы, дороги, места и регионы. Порядок полей задан парой
  `CMatrixRoadNetwork::Save/Load` в `MatrixGame/src/Logic/MatrixRoadNetwork.cpp`.

Изменение проходимости требует согласованно обновить `points`, `move` и
предвычисленный граф `roads`. Остальные таблицы нужно сохранять без потерь,
пока редактор не умеет их осмысленно пересчитывать.

## Консольная проверка

Цель `cmap_tool` собирается вместе с основным CMake-проектом. Она использует
родной `CStorage` движка и не меняет исходный файл:

```powershell
cmap_tool.exe inspect demo1.cmap
cmap_tool.exe roundtrip demo1.cmap demo1_copy.cmap
```

Выходной файл должен ещё не существовать. На штатной `demo1.cmap` и
`Abandoned_Tunnel.cmap` из PBNewMaps результат `roundtrip` побайтно совпал
с исходником. Структура, размеры и ссылки навигационного графа проверены
на 85 картах. Это проверка чтения и записи, не игрового поведения.

Первый этап редактора: просмотр карты и слоёв проходности. Далее — правка
отдельных объектов и параметров с сохранением неизвестных таблиц. Правку
геометрии и маршрутов следует добавлять после восстановления пересчёта
`roads` и проверки пасфайндинга на тестовой карте.
