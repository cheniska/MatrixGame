# robots.dat: чтение и правка

`CFG/Rus/robots.dat` — конфигурация планетарных боёв. Это контейнер `STRG`
версии 1: после восьмибайтного заголовка идут блоки `ZL03` (zlib), затем
таблицы `CStorage`. Движок восстанавливает из них дерево `CBlockPar`.
Штатный файл содержит два корня: `if` (интерфейс) и `da` (данные боя).
Оба нужно сохранить при обратной сборке.

`DATA/robots.pkg` — отдельный архив ресурсов: карты `.cmap`, модели `.vo`,
текстуры, звуки и другие файлы. Он не заменяет `robots.dat`.

## Утилита

Соберите цель `robots_dat_tool` через основной CMake-проект под Win32.
Требуется DirectX SDK June 2010, как и для MatrixGame. Используются
штатные `CStorage` и `CBlockPar` из `MatrixLib`.

```powershell
robots_dat_tool.exe decode CFG/Rus/robots.dat robots_if.txt robots_da.txt
robots_dat_tool.exe encode robots_if.txt robots_da.txt new_robots.dat
```

Выходные файлы должны ещё не существовать. Декодер создаёт UTF-16LE TXT
с BOM. При редактировании сохраняйте эту кодировку и синтаксис BlockPar:
`Имя { ... }` для блока и `Ключ=Значение` для параметра. Числовые и
строковые значения определяются местом их использования в исходниках
MatrixGame. После правки сначала соберите DAT в новый файл, затем снова
декодируйте его и сравните оба TXT с исходными.

На установленном `CFG/Rus/robots.dat` проверен побайтовый круговой проход
`DAT → TXT → DAT`: исходный и собранный DAT имеют одинаковый SHA-256.
Проверка изменения одного параметра в копии тоже прошла. Это проверка
формата, а не поведения в игре.

Для архивного `robots.pkg` можно использовать `srhd.py resource info/list/verify`
из SRHD ModKit 1.0.0. Правку карт `.cmap` эта утилита не выполняет.
